# Sairam Certify demonstration

Use `sairam-participation-template.pdf` with `participants-10.xlsx` or `participants-10.csv`. The ten participants are fictional adults, not real college records. Files have no email column and no messages are sent. Headers are exactly Name, Course, Issue Date. Default editor coordinates fit this template. It is marked DEMO ONLY / NOT OFFICIAL and has no institutional seal or signature.

For an authorized issuer with ready private storage, saved certificates and verification QR are enabled automatically. Guest/local-only PDFs are unverified and contain no verification QR. The blank template intentionally has no QR: valid QR links are created only when certificates are persisted.

The original template.pdf and participants.xlsx/csv remain the two-row regression fixture.
